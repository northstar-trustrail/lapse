Lapse warrant canaries that die loudly, on Arkiv

Every canary is an Arkiv entity whose Entity Expiration is its renewal deadline plus a grace period. Stop renewing and it vanishes from the query surface by itself. Trust comes from $creator, bound to a wallet published at the issuer's own /.well-known/lapse.json. This page has no backend: it queries the public Tiramisu RPC from your browser.

Check any issuer

Trust root here is whatever wallet you type; in production it comes from the issuer's domain.

Verify it yourself

No need to trust this page. Same query from a terminal:
git clone https://github.com/northstar-trustrail/lapse
cd lapse && npm ci
node cli/lapse.mjs check example-vpn   # exit 0 ALIVE, 1 OVERDUE, 2 LAPSED
